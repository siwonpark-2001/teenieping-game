# 💕 티니핑 이름 맞추기

캐치! 티니핑 시리즈에 등장하는 티니핑 캐릭터 이미지를 보고 이름을 맞추는 웹 퀴즈 게임입니다.

## 플레이

👉 **[게임 하러 가기](https://teenieping-game.vercel.app)**

## 기능

- 1기~6기 + 극장판 164마리 티니핑
- 기수별 필터 (전체 / 1~6기 / 극장판)
- 직접 입력 모드 / 4지선다 모드
- 힌트 기능 (첫 글자 공개)
- 점수 시스템 (정답 +10점, 힌트 사용 +5점)
- 게임 완료 후 결과 화면

## 로컬 실행

```bash
npx serve . -p 8080
# → http://localhost:8080
```

## 라이선스

캐릭터 이미지 저작권은 SAMG엔터테인먼트 / CJ ENM에 있습니다.
